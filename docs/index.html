Đủ để vận hành một server hosting

Từ tạo website đến backup, bảo mật và phân quyền khách hàng — trong một panel, không cần ghép nhiều công cụ.

Website và ứng dụng

  • Cài WordPress một lần bấm (WP-CLI) hoặc website PHP thường
  • PHP của mỗi website chạy bằng user Linux của chủ website
  • Nhiều phiên bản PHP, tên miền phụ cho mỗi website
  • MariaDB với phpMyAdmin đăng nhập một lần
  • SSL Let's Encrypt, quản lý file, cron

Backup và khôi phục

  • Backup website, backup cả tài khoản, lịch tự động
  • Đích lưu S3 (Wasabi, B2, R2, MinIO…) hoặc SFTP
  • Khôi phục từ server, đích lưu hoặc máy chủ khác qua SFTP/FTP/FTPS
  • Nhập backup từ DirectAdmin

Bảo mật

  • Tường lửa iptables + ipset, blocklist theo URL
  • WAF ModSecurity bật tắt theo website, chặn bad bot
  • Đăng nhập hai lớp (TOTP) và passkey
  • Nhật ký truy cập và các lần chặn

Hệ thống và khách hàng

  • Tổng quan tài nguyên và việc cần xử lý
  • Tự điều chỉnh PHP và MariaDB theo RAM/CPU
  • Người dùng, gói dịch vụ, hạn mức website và dung lượng
  • API cấp phát và module WHMCS

Làm việc hằng ngày

Những việc bạn làm mỗi ngày, ít bước hơn

Website, từ tạo mới đến cấu hình web server

Tạo website WordPress hoặc PHP, chọn phiên bản PHP, thêm tên miền phụ và chỉnh cấu hình ngay trên một màn hình: vhost và mẫu rewrite trên Nginx, .htaccess trên OpenLiteSpeed.

  • Mỗi tài khoản một user Linux; PHP của website chạy bằng chính user đó
  • Terminal chạy bằng user của website, chỉ cho các lệnh an toàn (Nginx)
  • Quản lý file: tải lên, sửa, nén và giải nén, phân quyền

Khôi phục theo từng bước, như DirectAdmin

Chọn nguồn, điền thông tin nếu cần, chọn tài khoản rồi khôi phục. Chạy nền, báo kết quả từng tài khoản; một tài khoản lỗi không làm dừng các tài khoản khác.

  • Nguồn: server này, đích lưu S3/SFTP, hoặc máy chủ khác qua SFTP, FTP, FTPS
  • Khoá SFTP được kiểm tra trước khi gửi mật khẩu
  • Backup đã lên đích lưu không chiếm thêm ổ đĩa của server

Bảo mật cho từng website

WAF ModSecurity bật tắt theo website, chặn bot theo User-Agent và rule tuỳ chỉnh. Trên Nginx có thêm bộ luật OWASP CRS và giới hạn HTTP flood.

  • Tường lửa iptables + ipset: một triệu địa chỉ vẫn nhẹ
  • Nhật ký truy cập cho biết request nào bị chặn và vì sao
  • Fail2ban và quét mã độc là tiện ích, bật khi cần
Tiện ích

Chỉ cài thứ server của bạn cần

Những phần không phải server nào cũng dùng được tách thành tiện ích, bật và tắt trong Cài đặt → Tiện ích.

Application

Chạy ứng dụng Node.js, container và Docker Compose sau Nginx.

Fail2ban

Chặn các địa chỉ dò mật khẩu SSH.

Quét mã độc

LMD + ClamAV: quét theo yêu cầu, theo lịch, giám sát thời gian thực và quét file tải lên.

Trợ lý AI (MCP)

Cho Claude Code, Cursor, VS Code đọc và thao tác panel bằng token cá nhân.

Quản lý DNS

DNS server ngay trên VPS bằng PowerDNS: zone và bản ghi A, AAAA, CNAME, MX, TXT, NS, SRV, CAA; website mới tự có zone.

Chế độ demo

Tài khoản demo công khai cho quản trị và khách hàng: xem mọi trang, không thay đổi được gì, có nút đăng nhập nhanh.

Thông báo

Cảnh báo quản trị viên qua email và Telegram: dịch vụ dừng, ổ đĩa đầy, backup lỗi, chứng chỉ sắp hết hạn…

Mọi tiện ích đều tắt mặc định. Gỡ tiện ích chỉ tắt tính năng, không xoá dữ liệu nó đã tạo; cài lại là dùng tiếp. Application và Quản lý DNS hiện có trên bản Nginx (BPanel).

Cài đặt

Từ VPS trắng đến panel chạy, bằng một lệnh

Lệnh cài hỏi bạn chọn web server: Nginx cài BPanel, OpenLiteSpeed cài OPanel. Trình cài của panel đó dựng web server, MariaDB, Redis, PHP, SFTP, certbot, phpMyAdmin, WP-CLI và tường lửa, rồi tự điều chỉnh PHP và MariaDB theo cấu hình VPS.

Chuẩn bị server

Ubuntu 24.04 mới cài, quyền root. Tuỳ chọn: một tên miền trỏ về IP để panel có SSL.

Chạy lệnh cài

Chọn 1 cho Nginx (BPanel) hoặc 2 cho OpenLiteSpeed (OPanel), rồi trả lời tên miền, cổng (mặc định 2222) và email SSL.

Đăng nhập

Địa chỉ, tên đăng nhập và mật khẩu được in ra cuối và lưu ở /root/login.txt.

bash <(curl -fsSL https://raw.githubusercontent.com/BNIX-VN/bpanel/refs/heads/main/panel-setup.sh)

Cài thẳng không cần chọn: thêm nginx hoặc openlitespeed vào cuối lệnh.

Yêu cầu hệ thống

  • Ubuntu 24.04 LTS, quyền root
  • Tối thiểu 1 vCPU / 1 GB RAM, khuyến nghị 2 vCPU / 2 GB RAM
  • Tiện ích Quét mã độc cần thêm khoảng 1,3–1,5 GB RAM khi quét

bpanel-update --release
bpanel

opanel-update

Mô hình bảo mật của BPanel

Panel không chạy bằng root

Tiến trình panel chạy bằng user hệ thống bpanel. Mọi việc cần quyền cao đi qua một script trợ giúp duy nhất thuộc root, chỉ chạy những thao tác nằm trong danh sách cho phép.

  • Helper kiểm tra tên miền, cổng, IP và đường dẫn trước khi gọi chương trình thật
  • Các tài khoản tách nhau bằng user Linux, SFTP chroot và shell nologin; mỗi website có open_basedir riêng
  • Cookie HttpOnly kèm CSRF, giới hạn đăng nhập, mật khẩu database mã hoá khi lưu
bpanel-api — user bpanel, unit systemd đã siết chặt
↓ sudo -n /usr/local/sbin/bpanel-helper <lệnh con>
bpanel-helper — root, chỉ các thao tác trong danh sách cho phép
↓ nginx · certbot · php-fpm · mariadb · iptables · useradd
Hỏi đáp

Câu hỏi thường gặp

Có mất phí không?

Không. BPanel và OPanel là mã nguồn mở theo giấy phép AGPL-3.0: bạn được dùng miễn phí, kể cả cho mục đích thương mại. Nếu sửa đổi rồi phân phối, hoặc cho người khác dùng bản đã sửa qua mạng, bạn phải công bố mã nguồn của bản đó theo cùng giấy phép.

Ai được hỗ trợ?

Khách hàng dùng VPS tại BNIX được BNIX hỗ trợ panel miễn phí, cả BPanel lẫn OPanel. Dùng VPS ở nơi khác, bạn vẫn dùng panel miễn phí và có thể báo lỗi qua GitHub Issues của BPanel hoặc OPanel.

Nên chọn Nginx hay OpenLiteSpeed?

Chọn Nginx (BPanel) nếu bạn quen cấu hình Nginx, cần bộ luật OWASP CRS, terminal cho website hoặc tiện ích Application (Node.js, Docker). Chọn OpenLiteSpeed (OPanel) nếu website của bạn dùng .htaccess hoặc bạn muốn LSCache cho WordPress. Hai panel cùng giao diện; lệnh cài hỏi bạn chọn một.

Có bản demo để xem thử không?

Có, mỗi web server một bản. OpenLiteSpeed (OPanel): bpanel-ols.bnix.io.vn:2222. Nginx (BPanel): bpanel.bnix.io.vn:2222. Trang đăng nhập có sẵn nút đăng nhập một chạm vào tài khoản quản trị hoặc khách hàng. Bản demo chỉ để xem: mọi thay đổi đều bị từ chối.

Chạy được trên hệ điều hành nào?

Ubuntu 24.04 LTS. Trình cài dừng lại nếu gặp hệ điều hành khác, để không để lại một server cài dở.

Tôi đang dùng DirectAdmin, chuyển sang được không?

Được. Tab Backup → Nhập DA nhập backup của DirectAdmin; tab Khôi phục lấy được backup từ server này, từ đích lưu S3/SFTP, hoặc từ một máy chủ khác qua SFTP, FTP, FTPS.

Khách hàng của tôi thấy gì?

Người dùng thường chỉ quản lý website của mình: file, database, SSL, WordPress, cron và backup, trong giới hạn số website và dung lượng của gói. Phần server chỉ quản trị viên thấy.

Có kết nối với WHMCS không?

Có. BPanel có API cấp phát và một module WHMCS dùng chung cho BPanel và OPanel: tạo, tạm khoá, mở khoá, xoá tài khoản, đổi gói, đổi mật khẩu và đăng nhập một lần từ khu vực khách hàng.

Cập nhật có ảnh hưởng website đang chạy không?

Dữ liệu, website và database giữ nguyên. Chạy bpanel-update --release (BPanel) hoặc opanel-update (OPanel), hoặc bấm cập nhật trong trang Cập nhật.

Gỡ một tiện ích có mất dữ liệu không?

Không. Gỡ tiện ích chỉ tắt tính năng; dữ liệu nó đã tạo được giữ nguyên để lần cài sau dùng tiếp.
